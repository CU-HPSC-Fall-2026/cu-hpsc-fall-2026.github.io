CSCI 5576/4576 - High Performance Scientific Computing
======================================================

Prof James Wright (he/him)

This is the course website for CSCI 5576/4576 at CU Boulder, Fall 2026.
This course covers computing systems, software, and methods used in solving large-scale problems in science and engineering.
It also explores topics such as computer hardware, computing system architecture, OpenMP, and MPI.

Assignments are accessible in the [GitHub organization repository](https://github.com/orgs/CU-HPSC-Fall-2026/repositories).
You should only be able to see the repository for your account.
